## 裁切与交互风险

- 若对原图使用**居中 `cover` 并保持完整高度**：4:3 视口保留原图 `x≈209–1463`；1:1 保留 `x≈366–1306`；9:16 保留 `x≈571–1101`。后两者会裁掉左侧数学地貌及右侧模型工坊，并把中央高对比平台放大为几乎唯一背景。实际 Graph 容器比例和 `background-position` 可不同，这些数字仅是静态几何示例。
- 当前 Graph 会平移/缩放节点与边。若图像固定在容器，背景轴线不能被解释为节点坐标；若图像随画布变换，其可读性和裁切会随 `fitView`/搜索跳转变化。集成方案须先明确世界背景与 DAG 的相机关系，避免装饰线被误读为 Strong Edge。
- `world-legend` 在画布左上，Controls 左下，MiniMap 右下；Drawer 与独立右侧进度栏已经消费了显著空间。现图没有给这些元素留出稳定低噪声区。

## 重新构图的验收条件

保持近—中—远空间叙事，但把**严格数学标注和高对比地标**移出 Graph Core；中央改为低对比方块地貌/雾层，局部数学纹理可见但不与节点或依赖线同粗同亮。数轴应避开底部控件或由前端独立呈现；右侧地标在 Drawer 开启后不能是唯一目标。用桌面宽屏、4:3、手机纵屏、Drawer 开/关，以及 32 节点/Strong 路径/Weak 显示状态进行实际叠加测试，并记录可读性截图。未经该测试不得把 v2 标为产品背景 `PASS`。
