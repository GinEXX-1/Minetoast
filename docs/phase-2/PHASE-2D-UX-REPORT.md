# Phase 2D — Function World UX Report

更新时间：2026-09-25。范围：本地应用集成与验收；没有生产部署、知识模型扩充或像素资产制作。

## 入口与边界

- 正式函数世界：`/function-world`；默认 `/` 继续显示 Phase 1 Legacy，并提供明确入口；`/?phase=2c` 候选预览保留。
- 运行时只读使用冻结的 Phase 2A/B/C fixture：32 Active Nodes、40 Strong、11 Weak、51 enabled edges、32 detail；没有修改稳定 ID、教材映射、Phase 1 测试 fixture 或数轴/平面直角坐标系的 `REVIEW_REQUIRED / LOW`。
- 函数世界进度以版本化 `localStorage` 保存于当前浏览器。它与 Phase 1 账户进度、API 和数据库完全隔离；没有跨设备同步，也不构成生产发布。

## 集成结果

|能力|实现与边界|
|---|---|
|图谱|React Flow + ELK 自上而下 DAG 布局；Worker 失败时使用确定性拓扑布局；Pan、Zoom、Fit、Center、Mini Map、悬停邻接高亮、模块定位均可用。|
|节点与边|普通/核心/Key 三级框体；Locked/Available/Unlocked 独立状态；Strong 默认实线并标示前置是否完成；Weak 为虚线，默认隐藏。Weak 不进入解锁状态投影。|
|解锁|普通点击仅在全部 Strong 前置完成时解锁；Locked 仍可打开详情。成功后目标弹跳、描边发光、粒子、后继唤醒、Toast、Strong 连线状态更新；Key 使用更强调的反馈。声音由全局开关控制，使用 Web Audio 合成提示音，无外部游戏素材。|
|快速初始化|点击目标后批量加入 Strong 祖先闭包和目标；Weak、旁支和无关节点不加入；祖先轻反馈、目标主反馈，批量过程不连续弹 Toast 或播放声音。完成后进入正常解锁模式。|
|搜索与路径|搜索命中后 Fly-to 与焦点高亮；支持内容索引的名称、成就、英文、全拼、首字母、符号与学生说法。`左右平移` 属冻结范围外，不伪造节点，明确提示待审核。提供 To、From、Between 三种路径；默认 Strong-only，显式开启完整关系时允许 Weak 辅助显示。|
|详情|32 个 P2C Detail 与节点一一关联；包含 Overview、定义、核心概念、公式条件、性质、直觉、推理、技能、例题、高考任务、易错点、教材双页码、重要度/难度、前后继关系。关系点击切换抽屉并定位新节点，组件按 Node ID 重新挂载，避免旧内容残留。|
|进度|全局与 7 个模块均按实际 unlocked 节点计数；不引入 XP、等级或推断能力分。|
|响应式|导航自动换行；平板以下进度侧栏移到图谱下方；窄屏抽屉限制在视口内；Mini Map 与画布控制分居两侧。1440、1024、768、390 px E2E 验证无页面水平溢出。|

## 工程验证

- 模型单测覆盖 Strong/Weak 状态隔离、普通解锁、Strong 祖先初始化、路径、搜索、版本化进度及 Key 数量。
- Playwright Chromium 已安装。完整 E2E：13/13 通过；Phase 2D 专项 4/4 通过，含真实浏览器搜索定位、抽屉关系跳转、初始化持久化、普通解锁、Weak 切换、路径和四档视口。
- 全部 Vitest：68 passed / 1 skipped；TypeScript、ESLint、Vite Build 均通过。
- 400 节点合成图的既有性能测试通过；此次产品页面仍只有 32 节点，不能把合成测试等同于未来 350+ 节点真实内容的用户体验验收。
- E2E 管理员发布用例会改变共享临时数据库的 graph head；已将该状态性用例排到其他回归用例之后。此前套件顺序导致 Phase 1 断言失败，单独 Phase 1 重跑及调整后的完整套件均通过。此排序仍是测试基础设施耦合，后续宜以独立数据库/项目彻底隔离。

## 已知限制

1. 数轴、平面直角坐标系的 Detail 仍为 `REVIEW_REQUIRED / LOW`，可读但未提升质量状态。
2. 函数世界进度当前仅保存在本浏览器；清理站点数据、换设备或浏览器会失去该进度。
3. 完整图在窄视口 Fit View 下节点较小；通过搜索、模块导航和缩放浏览，不代表最终移动 App 交互。
4. 最终像素图标、Sprite Sheet、领域背景、World Map 与生产部署均未执行。

停止条件：Phase 2D 集成与本地验收完成；不进入 Phase 3。
