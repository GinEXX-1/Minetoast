**DAG Validation**

Knowledge Graph 必须：

无循环。

不得出现：

A → B

B → C

C → A

  

**Duplicate Node Validation**

禁止：

同一个数学知识由于教材不同章节描述被重复建立节点。

  

**Dependency Validation**

每一条 Strong Edge 都必须回答：

如果学生不会 source，是否真的会显著阻碍 target？

答案不是明确 Yes：

降级为 Weak 或删除。

  

**Transitive Reduction Validation**

自动寻找：

A → B

B → C

A → C

并判断：

A → C

是否冗余。

  

**Orphan Validation**

检测：

不合理的孤岛节点。

允许真正的 Root。

但非 Root 知识应检查是否缺少 prerequisite。
