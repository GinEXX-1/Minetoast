# Phase 1 任务、风险与确认边界

**目标：用函数领域完成最小可信纵向切片，证明图谱、进度与交互闭环。以下保留原始验收基线；2026-09-19 的实施状态与证据见 PHASE1-DELIVERY.md。未完成 Knowledge Dependency Quality Gate 前，不宣告整阶段通过。**

建议范围：12–20 个经审核的函数高中考点 + 3–5 个必要初中前置；确有需求时另含最多 1–2 个跨领域连接目标。数量是上限建议，不为凑数生成节点；内容清单需先通过数学审核。只有一个地图占位区域、一套占位图标和合法占位声音。压力测试用匿名合成 DAG，不把它当正式数学节点。

## 2. 主要风险

|级别|风险|应对与验收证据|
|---|---|---|
|高|伪先修、考点颗粒度或示例被误当真实图谱|逐边五类质量输入 + Canonical 教材来源 + 反事实测试；LOW/冲突项不作为有效边发布|
|高|非级联撤销被通用解锁算法覆盖|已掌握最高优先级；链式撤销反例测试|
|高|初始化/导入/重试导致部分更新或重复反馈|单事务、revision、幂等结果；两连接并发与故障注入|
|高|管理员草稿影响学生图谱或漏未审核边|不可变 release + 原子 head；验证前后读取对照|
|高|服务端信任 userId/role 或泄露密码|会话决定身份、DTO 白名单、最小权限、双账户越权测试|
|中|大量 React 节点、公式、动画卡顿|摘要渲染、Worker、memo、懒加载、反馈合并；实际 trace|
|中|AIGC 图标数学含义错误、Sprite Sheet 网格失准|先占位，后小批生成，人工审核 crop；不先做全量素材|
|中|地图热点与底图不同步|统一归一化坐标系，缩放前后命中测试|
|中|字体/音效不可合法使用|许可记录，系统字体/合法占位，不让素材阻断业务|
|中|旧图版本与进度/备份不兼容|稳定 ID、退休不删、release 检查与导入差异预览|
|中|精确依赖版本兼容性未验证|01 锁定安装、typecheck、build；不假设“最新”互相兼容|
|中|无数据库运行环境导致结构未实测|02 第一时间真 PG18 执行与约束验证，未过不得接入持久化|
