## 已验证

|项目|结果|
|---|---|
|测试数据规模|20 个节点：3 个初中前置、17 个高中测试节点；28 条 Strong、3 条 Weak|
|三状态|Locked / Available / Unlocked 状态算法通过|
|Strong / Weak|Weak 不参与可解锁判断、初始化祖先闭包或进度统计|
|连线语义|Strong 连线按 source 掌握状态映射 ✅ / ❌；Weak 为可选虚线|
|图谱质量|无环、无重复边、无传递冗余、无未声明孤岛、无过度前置|
|初始化|目标和全部 Strong 祖先同一事务写入；不写 Weak 或旁支|
|撤销|只删除目标节点，后继已掌握记录保留|
|账户|密码 Argon2id 哈希、HttpOnly Cookie、同源和 CSRF 校验、两账户进度隔离|
|持久化|关闭并重新打开数据库后进度保持；注销再登录后进度保持|
|并发与可靠性|revision 冲突、幂等重试、异常回滚、非法批次全失败|
|编译|TypeScript strict 检查通过，Vite 生产构建成功|
|自动化测试|2 个测试文件、22 项测试全部通过|

## 尚未完整验证

- 原生 PostgreSQL 服务在当前运行环境中不可用。本轮使用 PostgreSQL 18.3 PGlite 执行同一份 DDL 和数据库集成测试；它不替代原生 PostgreSQL 的多连接并发与部署验收。
- 浏览器预览服务在会话恢复后停止，按预览恢复规则没有无限重启。React/XYFlow 页面已完成类型检查和生产构建，但 Pan、Zoom、Mini Map、Fit View、Fly-to 尚缺本轮可记录的真实浏览器操作证据。
- 20 个节点是结构与交互测试数据；依赖必须完成 Knowledge Dependency Quality Gate。当前未完成质量输入或独立 AI Review 的依赖为 `REVIEW_REQUIRED`，不会作为有效边发布；人工 override 是可选的可审计路径，不是统一发布前置。
- 未进行最终视觉、AIGC 素材、Minecraft 字体或音效验收。

## 结论

数据模型、领域算法、账户进度和前端构建已经达到 Phase 1 功能切片标准。进入下一阶段前，建议先由用户在本地实际操作画布，再决定是否调整节点交互；同时在可用的原生 PostgreSQL 18 环境补跑 `pnpm test:pg`。
