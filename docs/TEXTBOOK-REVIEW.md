## 历史签收方法（已被 Quality Gate 替代）

1. 使用本地 Canonical Source 而非互联网目录确认版本、章节与页码。
2. 对每条 Dependency 填写教材证据、数学定义、前置反事实、图谱上下文与 rationale。
3. HIGH 通过质量门；MEDIUM 需要两次独立 AI Review 一致；LOW、冲突与歧义为 REVIEW_REQUIRED。
4. 人工可抽检或记录 override，但不再要求所有节点和边逐项签审。

自动化测试中的“模拟审核”仅发生在独立临时数据库，用于验证权限与发布事务。它不是质量结论或人工签审证据。
