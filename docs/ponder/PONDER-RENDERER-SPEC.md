# Renderer Family v1

第二批通过共享 SVG 原语实现参数曲线、填充多边形、可换行标签、离散点列和圆集合区域 mask。三视图使用同一长方体的斜投影示意及三个尺寸矩形，属于二维分区演示，不提供自由相机。集合和统计场景复用二维渲染器，没有新增独立 renderer family。说明区可放到舞台下方，避免窄屏文字覆盖几何对象。

统一接口 `RendererProps` 输入 AnimationFrame、reduced-motion 标志、MathModel、合法 parameters、当前 step、可交互标志、参数更新与交互事件、辅助线状态和相机恢复序号。渲染器只解释数学对象，不检查 nodeId 或 demoId。

| Renderer | 实际实现 | 范围 |
| --- | --- | --- |
| CoordinateRenderer | SVG，等比例数学坐标 | 坐标网格、真实函数采样、点与投影、参数、线 |
| GeometryRenderer | 共享 SVG 数学原语 | 精确圆、圆周点、直线、解析交点、半径、直角标记 |
| SolidGeometryRenderer | Three.js + OrbitControls | 点、方向直线、透明平面、真实 L 形直角标记、辅助线、视角旋转/缩放/恢复 |

GeometryRenderer 复用二维渲染器是原语复用，不是独立切线硬编码。空间对象以世界坐标计算，WebGL 实际渲染，不用 SVG 假三维。3D line 目前显示有限可视段，不代表数学直线长度有限。plane 显示有限透明片，语义说明表明它代表平面。

性能目标 2D 60fps；实际设备表现需测量。固定采样预算、暂停取消 RAF、纯函数轨道统一推进，3D 缓存 Mesh / geometry / material，暂停后 WebGL change-event 按需渲染、设备像素比上限 2。不会因切步重挂整个应用。新对象需要 schema、数学模型、语义补偿、单元与浏览器验证一同扩展。

未实现的 renderer family：NumberLine、Set、Algebra、Statistics、Generic，以及 solids 中的完整立体图形/截面/相交等广泛能力。V1 三个 Pilot 不需要这些能力，不能把枚举或规划文档当作已经实现。

2D `draw`：曲线按自变量逐段构建，其端点始终位于数学曲线上；圆/标记使用归一化路径绘制，投影线真实延伸。3D `draw`：有限线段和直角标记按轨道伸展；平面逐步展开。所有动画视觉态均由共享 `AnimationFrame` 提供，不在各渲染器中创建独立计时器。

固定采样不保证自动识别采样点之间的极点（如 1/(x−0.0123)）。当前场景均为连续函数。新增不连续表达式必须单独处理分段与渲染证据，不得只凭数值冒烟放行。

首批扩展支持二维线段箭头、函数部分轨迹、三维端点线段和正交基上的圆弧。三维线段以缓存圆柱显示主体，圆弧以 32 段缓存圆柱构建，参数变化只更新世界坐标变换。所有渲染器读取同一偏好颜色；日间模式使用深色线条，夜间空间场景针对明亮棋盘底座使用深青/深金主体，标签使用深底色块。用户自选色优先于自动配色，可随时恢复默认。
