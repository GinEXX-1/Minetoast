## 动画流程

[完整动画流程](PONDER-ANIMATION-FLOWS.md) 从执行中的 DSL 生成，每步列出构建、显现、强调、参数变化、说明及公式出现时间。运行 `pnpm ponder:storyboard` 可重新生成。三个 Pilot 的核心过程：

- 单调性：绘制曲线与区间 → 放入两点 → 延伸投影并连续比较函数值 → 自由拖动 → 保留实验值并展示定义。
- 圆切线：绘制圆并显现 O/P → 引入割线、两个解析交点连续合并 → 连接 OP 并绘制直角 → 沿圆周移动 P 检查不变量。
- 线面垂直：展开平面、绘制面内相交线与 P → 构建 l、依次形成两组 L 形正交标记 → 强调相交条件 → 依次突出条件并显示定理 → 自由观察。

全部渲染器使用相同时间轴，暂停冻结，重播重置轨道；自由实验后的参数不会被下一帧重置。3D 只更新缓存对象的变换/缓冲区，不逐帧销毁重建。观看完成不改解锁、掌握或 Strong/Weak。

## 独立审核

[独立审核报告](PONDER-INDEPENDENT-REVIEW.md) 包括八场景的解析数学论证、43,956 组单调性输入及其他边界交叉求值。审核发现并修复：实验续播重置、最佳视角被覆盖、通用平面缩放、单位圆坐标轴、畸形审查 JSON 放行，以及完成后播放器无法跳转重播。

审核者复核修复，主线程以浏览器回归确认实际行为。没有外部模型服务依赖，不生成 AI 候选或自动发布。

## 交付边界

8 个场景的数值冒烟问题为0。正式 `pnpm ponder:gate` 仍按设计返回 REVIEW_REQUIRED/退出码1：本地独立工程审核不伪造正式教材逐页核验和全部教研维度 HIGH 证据。门禁拒绝畸形记录、过期digest、同创作者审核和非法数学场景。

本次交付为本地可执行引擎与人工创作场景，没有生产发布端点或云端观看进度同步。固定采样对采样点之间的极点没有自动断线保证，新增不连续函数需要单独处理；当前八场景连续。实机触摸、低端GPU、手机3D、真实屏幕阅读器和WebGL中断恢复尚无实机证据，详见独立报告。

## 实际浏览器问题修复（2026-10-02 22:23 CST）

用户在 1163×905 的 Codex 内置浏览器反馈静止动画和入口贴边。现场读取 `matchMedia('(prefers-reduced-motion: reduce)').matches` 为 true；旧实现直接绘制终态，但仍推进时间轴并显示“演示中”。此前模拟减少动态效果的测试只检查可操作性，没有检查这项状态矛盾。

修复后默认静态模式停止计时，显示原因，允许通过“播放动画”或“启用动画”显式重播当前步骤；该选择仅作用于当前演示，不修改浏览器或系统设置。静态模式仍支持逐步浏览、实验和完成观看。现场保留媒体查询为 true，已验证显式播放的 elapsed / camera 连续变化、暂停值冻结及重播。

入口的 `.world-drawer section` 把 padding 覆盖为 `15px 0`，按钮也被知识世界通用样式覆盖。入口样式增加限定范围，实际 computed padding 恢复 18px，按钮恢复绿色并保持卡片内侧留白。

本次检查：构建/类型检查、lint、diff 检查通过；18 项 Ponder 浏览器检查通过，最终微调后重跑 8 项相关检查全部通过；15 项 Ponder 单元/集成检查通过。未重新运行无关系统的完整 E2E。新增入口检查覆盖 1440/1163/390px，既有减少动态效果检查覆盖 768/390px。现场截图：`evidence/entry-fixed-actual-browser.jpg`、`evidence/motion-fixed-actual-browser.jpg`。
