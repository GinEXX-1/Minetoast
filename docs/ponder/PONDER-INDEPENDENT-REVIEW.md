## 独立数学依据

| 场景 | 解析论证 |
| --- | --- |
| 函数单调性 | 在 0≤x₁<x₂≤3，x₂²−x₁²=(x₂−x₁)(x₂+x₁)>0 |
| 圆切线 | P=2(cosφ,sinφ)，方向 d=(-sin(φ+θ),cos(φ+θ))，交参数根为 0、4sinθ。θ→0 合并；θ=0 时 P·d=0 |
| 线面垂直 | a=(1,0,0)，b=(cosβ,0,sinβ)，a×b=(0,-sinβ,0)≠0，β∈[0.35,2.8]；l=(0,1,0) 与二者正交 |
| 二次函数参数 | y=ax²，非零 a 的符号决定开口，固定非零高度处宽度与 1/√|a| 成比例；a=0 是明确的退化情形 |
| 函数零点 | x²−4=(x−2)(x+2)，零点为实数 ±2，交点为坐标点 |
| 一次函数斜率 | f(0)=1 且 Δy=kΔx；k=0 对应常数函数 |
| 单位圆 | P=(cosφ,sinφ)，cos²φ+sin²φ=1 |
| 导数切线 | 有限差商=((x₀+h)²−x₀²)/h=2x₀+h，h≥0.05；极限为 2x₀ |

独立执行 43,956 组单调性输入、1,001 组圆/单位圆/空间夹角/差商交叉检查。单调差最小 0.0025，空间叉积模最小约 0.334988；最大浮点残差约 8.4×10⁻¹⁵。数值检查是交叉验证，上表解析论证提供数学依据。

- 截图与代码审核不证明教研效果，也不替代教材版本逐页核验、生产发布签审。正式 gate 继续保留 REVIEW_REQUIRED。
