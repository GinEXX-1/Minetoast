## 证据状态与质量裁决字段

|字段值|含义|
|---|---|
|`DIRECT`|教材在定位页直接呈现节点所述核心概念或性质；仍不代表内容审批。|
|`PARTIAL_CONTEXTUAL`|教材在特定上下文使用或提及相关概念，但不足以覆盖当前节点的全部定义、条件或粒度。|
|`NO_LOCATED_EVIDENCE`|在可读取的 Canonical Corpus 中未定位到足以填写该节点的教材位置。|
|`SOURCE_UNREADABLE`|可能相关的 Canonical 源文件不可读取，无法从本地语料库确认。|
|`REVIEW_REQUIRED`|页码、版本、目录位置或教学判断尚需人工确认。|

每条 Dependency 必须综合 Canonical Textbook Evidence、数学概念定义、前置反事实测试、全图结构上下文和具体 rationale。图结构检查只验证结构，不决定数学前置关系。

|质量结论|含义|
|---|---|
|`KEEP_STRONG`|确认 source 是 target 指定能力的必要解锁前置。|
|`DOWNGRADE_TO_WEAK`|相关但不是必要解锁前置。|
|`REMOVE`|不应保留该依赖。|
|`REVIEW_REQUIRED`|证据或教学判断不足，未作裁决。|

|置信度|通过规则|
|---|---|
|`HIGH`|完整五类输入支持且无冲突时，可由质量门自动通过。|
|`MEDIUM`|必须有两次独立 AI Review 且结论、置信度一致，才通过。|
|`LOW`|自动归入 `REVIEW_REQUIRED`。|

定义歧义、Canonical evidence 冲突、AI Review 冲突或第二轮 AI Review 缺失，同样归入 `REVIEW_REQUIRED`。`REVIEW_REQUIRED` 边不会作为有效 Strong Edge 发布，但不会阻断其他已通过节点或边；人工 override 仍可用，且必须记录操作者、时间和理由。

`printed_page` 与 `pdf_page` 必须分别读取，禁止互换。带 `REVIEW_REQUIRED` 的页面不是零页、也不是默认首页。

## Quality Gate 执行要求

1. 对节点核对原创定义、公式、条件与所列教材页是否相符；`PARTIAL_CONTEXTUAL` 不得误写为直接证据。节点不再要求逐项外部人工签审才可进入候选发布。
2. 对每条 Dependency 填写五类质量输入，尤其回答“若未掌握 source，是否显著阻碍 target 核心能力”。章节顺序、同页出现和案例引用不是 `KEEP_STRONG` 的理由。
3. `HIGH` 可自动通过；`MEDIUM` 必须记录两个不同 `reviewer_run_id` 的独立 AI Review，且无结论冲突；`LOW`、冲突或定义歧义自动为 `REVIEW_REQUIRED`。
4. `REVIEW_REQUIRED`、`REMOVE` 依赖在候选快照中禁用；`DOWNGRADE_TO_WEAK` 以 Weak 发布；只有已通过的 `KEEP_STRONG` 才以 Strong 发布。孤儿、环、传递冗余和 overconnected 仍由 Graph Validator 报告，但不充当数学判断。
5. 人工可记录 override，不必逐条签审。override 仍须保留 Canonical evidence、数学定义、反事实、图谱上下文和具体理由；本文件不代替应用内审计记录。
