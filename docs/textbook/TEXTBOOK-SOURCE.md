## 稳定引用格式

```text
PEP-A:<book>:C<chapter>:S<section>
```

示例：`PEP-A:B1:C1:S1.1`。其中 `book` 是 `B1`、`B2`、`X1`、`X2` 或 `X3`；`C` 和 `S` 保留教材的印刷编号，而非按本项目重新编号。章节级定位省略 `:S...`，例如 `PEP-A:X1:C2`。

每个可用定位同时保存两个数值：

- `pdf_page`：PDF 阅读器中的一基页号；
- `printed_page`：教材页面印刷页码。

两者禁止互换。`TEXTBOOK-INDEX.md` 的每行都显式列出两者。未能从源文件可靠取得的字段一律写作 `REVIEW_REQUIRED`。
