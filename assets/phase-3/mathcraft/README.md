# MathCraft Item assets

The source of truth is `apps/web/src/MathCraftIcon.tsx`: original, transparent, integer-aligned 32×32 SVG designs. Review boards in this folder are browser-rendered evidence, not runtime sprite sheets. No Minecraft texture, inventory sprite, frame, or item asset is imported.

Current stage: 12 representative icons were reviewed first; the remaining 20 were then added for a complete 32-node candidate set. The review boards are `p3c-representative-board.png`, `p3c-32-item-inventory.png`, and `p3c-state-sample.png`. Approval status is recorded in `docs/phase-3/P3C-ICON-ACCEPTANCE.md`.
